# Brazil Car Price Scraper

## Project Description

This project collects automobile data from the Brazilian FIPE API, including brand, model, year, fuel type, and price information.

## Data Source

* FIPE API (https://parallelum.com.br/fipe/api/v1)

## Features

* Fetch car brands
* Fetch car models
* Fetch year and fuel types
* Fetch real market price data
* Export structured data to CSV

## Output

* brazil_car_full_price_data.csv

## Technologies Used

* Python
* Requests
* Pandas
